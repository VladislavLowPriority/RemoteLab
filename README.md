# CSTLab SPBPU — Remote Lab Hub (Releases)

Official desktop client builds for the remote laboratory **CSTLab SPBPU (Remote Lab Hub)**.

## Download & Install (English)

Download the latest release from **[Releases](https://github.com/VladislavLowPriority/RemoteLab/releases/latest)**:

- **`RemoteLabHub-Setup-<version>.exe`** (~250 MB) — full installer for a clean installation.
- **`RemoteLabHub-Update-<version>.exe`** (~51 MB) — lightweight update package for existing installations (`0.9.0+`); future updates are downloaded automatically by the app from here (`update.json`).
- **`update.json`** — auto-update manifest (`https://github.com/VladislavLowPriority/RemoteLab/releases/latest/download/update.json`).

## Установка и обновление (Русский)

Скачайте последний выпуск со страницы **[Releases](https://github.com/VladislavLowPriority/RemoteLab/releases/latest)**:

- **`RemoteLabHub-Setup-<version>.exe`** (~250 МБ) — полный установщик для новой установки.
- **`RemoteLabHub-Update-<version>.exe`** (~51 МБ) — лёгкий пакет обновления поверх установленной версии `0.9.0+`; дальнейшие обновления программа скачивает сама отсюда же.
- **`update.json`** — манифест автообновления (`https://github.com/VladislavLowPriority/RemoteLab/releases/latest/download/update.json`).
