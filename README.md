# CSTLab SPBPU — Remote Lab Hub (Releases)

Официальные сборки клиента удалённой лаборатории **CSTLab SPBPU (Remote Lab Hub)**.

## Установка

Скачайте последний полный установщик из раздела **[Releases](https://github.com/VladislavLowPriority/RemoteLab/releases/latest)**:

- `RemoteLabHub-Setup-<version>.exe` — полный установщик для новой установки (~250 МБ)
- `RemoteLabHub-Update-<version>.exe` — пакет обновления поверх установленной версии `0.9.0+` (~51 МБ, скачивается программой автоматически)
- `update.json` — манифест автообновления (`https://github.com/VladislavLowPriority/RemoteLab/releases/latest/download/update.json`)
